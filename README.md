# 2.7 - Broken Code

## Actividad: Depuración de Código

Este repositorio contiene la resolución de la **Actividad 2.7**, enfocada en la práctica de técnicas de depuración (*debugging*) en JavaScript.

El objetivo principal es identificar, analizar y subsanar distintos tipos de fallos comunes en programación:
- **Errores sintácticos**: Errores que impiden la compilación o interpretación del código.
- **Errores lógicos**: Fallos en la lógica de control, condiciones o algoritmos que producen resultados incorrectos.
- **Errores en tiempo de ejecución (*Runtime / ReferenceError*)**: Variables no definidas, desbordamientos de índices o referencias erróneas.
